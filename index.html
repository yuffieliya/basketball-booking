Netlify部署说明

要将此系统部署到Netlify并查看所有预约申请，请按照以下步骤操作：

  1. 将本HTML文件保存为index.html
  2. 创建一个GitHub仓库，并将文件上传
  3. 登录Netlify，选择"New site from Git"
  4. 连接您的GitHub仓库并部署
  5. 部署完成后，在Netlify后台的"Forms"选项卡中查看所有预约提交
// 在Netlify后台查看预约记录的步骤：
1. 登录Netlify账户
2. 选择您的站点
3. 点击左侧菜单的"Forms"
4. 选择"booking-form"查看所有提交
